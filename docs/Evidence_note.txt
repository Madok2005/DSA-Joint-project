Which fields were directly observed: The location names:the branches, wings, floors, and rooms (IAC, Knowledge Commons, Discussion Room, Research Commons, Reading Room, 24-Hour Reading Room, Braille Room, the A–Z zones).The area/wing/floor of each space (West Wing, East Wing, ground/upper floors).

5. Which fields were estimated/derived/modelled:
The coordinates (x_coord, y_coord); a local grid placed by approximate position, not measured with GPS or a tape.
The distances and travel times on routes- estimated, not stopwatch-timed (yet).
The condition_weight values — assigned by judgement (stairs = higher), not formally scored.
Most of the 300 service requests — modelled to reflect realistic library patterns and peak/off-peak behaviour, with my own sequential IDs, not copied from real patron records.
The urgency, deadline and status values — set by realistic rules per request type.
The exact staff counts and availability — estimated from typical shift patterns rather than a live roster.

The project brief requires the final dataset to be Ghana-localised and privacy-respecting.
